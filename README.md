# 🎓 uniConnect

### University Student Platform

**uniConnect** is a web-based university platform designed to help students connect, share information, and interact with their university community through a centralized system.

The platform brings together useful student services such as **course reviews, university events, forums, and student discussions** in one place.

## ✨ Features

* 📚 **Course Reviews** — Students can view and share reviews about courses.
* 📅 **Events** — Discover and share university-related events.
* 💬 **Forums** — Students can create discussions and exchange information.
* 👥 **Student Interaction** — Connect and communicate with other students.
* 🔐 **User Accounts** — Registration and login functionality.
* 🏫 **University Information** — Centralized access to student-related information.
* 📱 **User-Friendly Interface** — Simple and accessible web interface.

## 💻 Technologies

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** PHP
**Database:** MySQL
**Database Management:** phpMyAdmin
**Development Environment:** XAMPP, Visual Studio Code

## 🗄️ Database

uniConnect uses **MySQL** to store and manage application data, including user accounts, course information, reviews, events, and forum-related content.

## 🎯 Project Goal

The goal of uniConnect is to provide students with a centralized platform where they can **access university-related information, share experiences, discover events, and communicate with other students**.
